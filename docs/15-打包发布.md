# 打包发布

ENERGY Designer 支持多平台安装包制作，可将编译后的应用程序打包为各平台标准的安装格式。

## 平台支持

### macOS

| 打包格式     | 说明                      |
|-----------|-------------------------|
| `.pkg`    | macOS 标准安装包             |
| `.dmg`    | macOS 磁盘映像文件            |
| Universal Binary | 同时支持 amd64 和 arm64 架构 |

**功能特性：**
- 自动创建 `.app` 应用包结构
- 自动生成 `Info.plist` 配置文件
- 自动处理应用图标（`.icns`）
- 使用系统内置签名工具进行代码签名（`codesign`）
- 支持 Universal Binary 构建（amd64 + arm64）

### Windows

| 打包格式      | 说明                 |
|------------|--------------------|
| `.exe` 安装程序 | 使用 NSIS 脚本生成安装程序    |
| AppX       | Windows 应用商店格式     |

**功能特性：**
- 自动生成 NSIS 安装脚本
- 自动生成 `.ico` 图标文件
- 自动生成 `manifest` 文件（支持 UAC、DPI 感知等）
- 自动生成 `.syso` 资源文件（版本信息嵌入）
- 支持系统签名工具签名

### Linux

| 打包格式       | 说明                    |
|-------------|-----------------------|
| `.deb`      | Debian/Ubuntu 安装包     |
| `.rpm`      | Red Hat/CentOS 安装包    |
| `.AppImage` | 通用 Linux 应用格式        |

**功能特性：**
- 支持 GTK2/GTK3 运行时选择
- 自动处理 `libenergy.so` 动态库依赖
- 支持 GTK3 的 `webkit2gtk` 依赖
- AppImage 格式支持离线依赖集成
- 支持依赖检查和自动安装

## 资源嵌入

打包过程中自动处理以下资源：

| 资源类型          | 说明                             |
|----------------|--------------------------------|
| 应用图标          | 自动转换为各平台格式（.ico / .icns / .png） |
| 版本信息          | 自动嵌入到可执行文件中                    |
| Manifest 文件    | Windows 下自动生成并嵌入               |
| 框架运行时         | 自动打包必要的框架库文件                  |

## 代码签名

### macOS 签名

使用系统内置的 `codesign` 工具进行签名：
- 预览运行时使用开发签名（`-` 即 ad-hoc 签名）
- 打包发布时支持指定开发者证书签名

### Windows 签名

支持使用系统签名工具对可执行文件和安装包进行签名。
