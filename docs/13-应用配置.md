# 应用配置

应用配置用于设置应用程序的元数据信息，如标题、图标、版本号、权限等。通过 **设置 > 应用配置**（快捷键 `Ctrl+F11` / macOS `Cmd+F11`）打开。

## 通用配置

| 配置项       | 说明                   |
|-----------|----------------------|
| 应用标题      | 应用程序的显示名称            |
| 应用 ID     | 应用程序的唯一标识符（反向域名格式）   |
| 应用描述      | 应用程序的描述信息            |
| 版权信息      | 应用程序的版权声明            |
| 版本号       | 应用程序版本号（如 1.0.0）     |
| 应用图标      | 应用程序的图标文件（支持 PNG）    |

## 图标设置

- 支持上传 PNG 格式的图标文件
- 设计器自动将 PNG 转换为各平台所需格式：
  - **Windows** - 自动生成 `.ico` 格式
  - **macOS** - 自动生成 `.icns` 格式
  - **Linux** - 使用 `.png` 格式
- 图标自动缩放到各平台要求的标准尺寸

## Windows 配置

### Manifest 设置

| 配置项                              | 说明                |
|----------------------------------|-------------------|
| 兼容性操作系统 (Compatibility OS)      | 目标 Windows 版本     |
| DPI 感知                          | 高 DPI 支持设置       |
| 运行级别 (Run Level)                 | 权限运行级别（普通/管理员）   |
| UI Access                        | UI 访问权限           |
| 自动提升 (Auto Elevate)              | 自动请求管理员权限        |
| 禁用主题 (Disable Theming)           | 禁用窗口主题           |
| 禁用窗口过滤 (Disable Window Filtering) | 禁用窗口过滤           |
| 高分辨率滚动感知                       | 高分辨率显示器滚动支持      |
| 超高分辨率滚动感知                      | 超高分辨率显示器滚动支持     |
| 长路径感知                           | 支持超过 260 字符的路径   |
| 打印机驱动隔离                        | 打印机驱动程序隔离        |
| GDI 缩放                          | GDI 缩放支持          |
| 段堆 (Segment Heap)                | 段堆内存管理            |
| 使用通用控件 V6                      | 使用 Common Controls v6 |

## macOS 配置

### Info.plist 设置

| 配置项                    | 说明                     |
|------------------------|------------------------|
| Bundle Executable      | 可执行文件名                 |
| Bundle Name            | 应用包名称                  |
| Bundle Display Name    | 应用显示名称                 |
| Bundle Localizations   | 支持的语言本地化               |
| Bundle Identifier      | 应用唯一标识符                |
| Bundle Version         | 内部版本号                  |
| Bundle Short Version   | 短版本号                   |
| Bundle Get Info String | 简介信息                   |
| Bundle Icon File       | 图标文件名                  |
| Copyright              | 版权信息                   |
| LSUIElement            | 是否为后台应用（不在 Dock 显示）    |
| LS Minimum System Version | 最低系统版本要求             |

## 保存配置

修改配置后点击"保存"按钮，配置信息写入项目的 `.egp` 配置文件。同时自动更新应用图标文件到项目的资源目录。
