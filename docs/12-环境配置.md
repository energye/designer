# 环境配置

环境配置用于设置设计器运行所需的 Go 语言环境，通过 **设置 > 环境配置**（快捷键 `Ctrl+F10` / macOS `Cmd+F10`）打开。

## 配置项

### Go Root 路径

设置 Go 语言安装根目录（GOROOT）。设计器使用此路径查找 Go 编译器和工具链。

- 支持配置多个 Go 安装路径
- 通过下拉框选择当前使用的 Go 版本
- 点击浏览按钮可选择自定义的 Go 安装目录

### Go 版本检测

设计器会自动检测系统中已安装的 Go 版本，并显示检测状态。Go 1.20 或更高版本为必需。

## 环境变量

设计器会自动初始化 Go 相关环境变量（GOPROXY、GOSUMDB 等），确保依赖下载正常工作。

## 配置保存

环境配置保存在设计器的全局配置文件中，对所有项目生效。
