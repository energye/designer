# 构建选项

构建选项用于配置项目的编译和打包参数，通过 **设置 > 构建选项**（快捷键 `Ctrl+F9` / macOS `Cmd+F9`）打开。

## 构建配置

### 基本设置

| 配置项     | 说明                                     |
|---------|----------------------------------------|
| 目标平台    | 编译目标操作系统（Windows / macOS / Linux）        |
| 目标架构    | 编译目标 CPU 架构（amd64 / arm64 / 386 / arm）   |
| 输出目录    | 编译输出文件的存放目录                            |
| 可执行文件名  | 编译生成的可执行文件名称                           |

### 编译选项

| 配置项        | 说明                     |
|------------|------------------------|
| 编译模式      | Debug（调试）或 Release（发布） |
| 优化选项      | 是否启用编译优化               |
| 去除调试信息    | 是否使用 `-s -w` 去除调试符号    |
| 隐藏控制台窗口  | Windows 下隐藏控制台窗口        |
