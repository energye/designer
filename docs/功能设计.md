- 3.4 UI 布局文件生成

### 代码结构
#### UI
1. Go LCL代码创建Designer UI布局和功能
2. 主窗口为上部分和下部分
- 2.1 上部分, 左侧: 运行工具 右侧: 组件选项卡
- 2.2 下部分, 左侧: 组件树, 组件属性 右侧: 组件设计界面(FormTab)
- 2.2.1 组件设计界面(FormTab) 一个组件树, 一个窗体 Form 根节点它用于显示在组件树结构, 设计器处理器
- 2.2.2 组件设计界面(FormTab) 根组件窗体, 树结构

#### 数据载体与设计组件 DesigningComponent
- 树结构(父节点和子节点)
- 每个组件有一个独立的控制功能, 设计组件有单独的组件属性树(组件属性, 组件事件)
- 设计组件数据更新, 每个组件有自己的属性列表和事件列表, 使用反射调用函数更新设计时效果, 使用节点数据更新属性树


### 生成
` 设计器窗体: 组件属性变更 → JSON UI文件(form.ui) → Go代码生成 → 运行生成的Go代码`

方案一 生成UI布局代码
```
project/
├── forms/
│   ├── main_form.ui.go     # 自动生成（禁止手动修改）
│   ├── main_form.go        # 用户代码（可手动修改）
│   └── main_form.ui        # UI布局文件
```
方案二 运行时绑定
```
project/
├── forms/
│   ├── main_form.ui        # UI布局文件
│   ├── main_form.go        # 用户代码（可手动修改）热加载 UI 布局文件

type MainForm struct {
    *TForm
}

func NewMainForm() *MainForm {
    form := &MainForm{}
    form.loadUI("main_form.ui")
    return form
}
```

#### UI 布局文件 form[n].ui JSON 格式
- 根据设计器窗体信息, 时时生成, 保存到 ui 文件

#### Go代码生成 
- 根据 ui 文件生成 go 代码

#### 预览
- 运行生成的Go代码

#### 设计器构建&打包
- 自动编译打包必要的框架模块资源
